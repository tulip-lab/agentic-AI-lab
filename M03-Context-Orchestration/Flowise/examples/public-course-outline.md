# Public sample course outline: Privacy in Published Statistics

This is a fictional, public teaching document for the M03 Flowise labs. It does not describe a real university course or assessment.

The four learning steps are: (1) build a basic Flowise Chatflow; (2) compare a prompt with and without case context, then test conversation memory; (3) retrieve information from approved public documents; and (4) observe an Agent calling a narrowly scoped tool.

The activity asks learners to distinguish a generated answer from a retrieved source and from a tool result. The outline does not specify an exam date, any person's salary, an internal marking rubric, or a deployment approval.
