# Data Privacy 共享教学案例（v3）

本案例用虚构课程的学习分析方案，贯通 **隐私泄露、数据泄密、差分隐私** 三个不同问题。所有人物和资料均为原创合成内容；它不是法律意见、机构政策或实际泄密事件。文本许可 CC BY 4.0，代码沿用仓库 MIT 许可。

| 概念 | 虚构情境 | 教学判断 |
| --- | --- | --- |
| 隐私泄露（DP-LEAK） | 小分组统计或重叠查询让人推断个人情况 | 检查发布粒度、查询组合与可识别性 |
| 数据泄密（DP-BREACH） | 原始学习记录被未授权导出 | 核查访问、导出权限与事件处理 |
| 差分隐私（DP-DP） | 向外发布统计结果 | 讨论随机化机制、ε、累计损失与统计误差 |

DP-MIN 提供数据最小化背景。差分隐私针对**统计发布中的个体推断风险**，不能补救原始记录泄密；即使使用差分隐私，也要独立管理访问权限与事件响应。较小的 ε 通常对应更强的保护，但可能增加统计误差；多次发布须考虑隐私损失的组合。这里不计算 ε、不演示真实数据集，也不声称某个参数已足够安全。

`corpus.json` 是逐字引用的教学语料，`task.json` 给出默认任务，`boundary-scenarios.json` 包含缺证据、已标注来源冲突和越权指令等停止场景。v1/v2 保留为旧版；本版是默认贯通样板。来源编号便于核查，不构成合规认证。

差分隐私技术解释参考 [NIST SP 800-226](https://csrc.nist.gov/pubs/sp/800/226/final) 与 [NIST 入门说明](https://www.nist.gov/blogs/cybersecurity-insights/differential-privacy-privacy-preserving-data-analysis-introduction-our)。课程使用时只替换为经许可的公开或合成资料，不输入真实学生、客户或保密研究数据。
