# Data Privacy / AI Security 共享课程案例

这是原创合成的微型教学语料，面向课程资源设计，不构成法律意见或任何大学的正式政策。内容许可 CC BY 4.0，代码遵循仓库 MIT 许可。

corpus.json 包含四段教学知识、两段冲突的虚构保存期片段，以及一段明确不可信的讨论区文本；task.json 定义受众、主题与来源选择。case-manifest.json 记录逐文件 hash 和来源。来源编号用于核查，不意味着内容获得法律合规认证。

用公开案例完成教学目标、材料、练习和来源核查，再讨论如何迁移到自己的课程。不要替换成学生成绩、客户数据或保密研究材料。

## 版本二边界案例

新增 RETENTION-A/B 两段互相矛盾的虚构保存期文本，以及 boundary-scenarios.json 中的正常、缺证据、来源冲突、越权指令场景。两段保存期不是 BTBU 或其他机构的政策；冲突只在所选资料中显式标注时触发。v1 作为原始版本保留。
