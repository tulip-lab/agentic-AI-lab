## 单个版本记录

### 版本编号

填写 `V0`、`V1`、`V2` 或后续编号。

### 目标要求或已诊断的问题

说明本版本只针对哪一项要求或哪一个问题。

### 假设

在生成之前，说明你预计这次修改会产生什么效果。

### 完整 Positive Prompt

逐字粘贴实际使用的 Prompt。

### 完整 Negative Prompt

逐字粘贴实际使用的 Negative Prompt；如果未使用，请填写 `未使用`。

### 参考输入与设置

记录每个参考文件、可见的参考权重、模型设置、随机种子（如有）及本版本使用的其他控制参数。
说明该服务是通过免费服务、免费额度、学校提供的访问权限还是已有个人订阅使用的；不要填写价格、账户或付款信息。

### 受控修改

准确说明与上一个版本相比修改了什么、哪些条件保持不变。
如果更换了模型或服务，必须明确说明，并将其视为平台与 Prompt 同时变化，而不是只比较 Prompt。

### 输出证据

填写原始输出文件名和 Contact Sheet 文件名。

### 可比较的评分

所有版本必须使用相同的判断规则。

| 分数 | 判断标准 |
| ---: | --- |
| 5 | 与参考要求高度一致，没有可见的实质性缺陷。 |
| 4 | 基本一致，仅有不影响场景或动作的轻微缺陷。 |
| 3 | 整体可辨认且大致正确，但一个或多个明显缺陷削弱了吻合度。 |
| 2 | 重大偏差、不稳定或瑕疵破坏了预期结果。 |
| 1 | 相关要求缺失、错误或结果无法使用。 |

| 衡量指标 | 1-5 分 | 支持该分数的证据 |

### 评估

本次干预是否改善了目标指标？
它是否导致其他指标退步？
请使用固定检查点的证据回答，不要只给出总体印象。

### 诊断与下一步行动

将结果判断为任务描述失败、参考材料使用失败、能力或控制限制，或者成功干预。
说明支持该判断的证据，以及下一次只准备测试的一项修改。
